# PROJECT INTERNET — Project overview

PROJECT INTERNET is a self-contained miniature internet made of user-created websites connected by fictional internal addresses. The platform provides the environment; user websites will eventually have independent creative identities.

## Product pillars
- Create fictional domains and websites.
- Publish pages and connect them through links.
- Browse and search the internal web.
- Discover relationships between sites.

## Current scope
Milestone 1 establishes the monorepo, landing page, browser entry interface, API health check, and local database configuration. Domain resolution, accounts, editing, search, crawling, and network exploration are future work.
