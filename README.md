# PROJECT INTERNET

A miniature internet made of user-created websites with fictional internal domains.

## Status

Milestone 1 foundation is under construction. The current scope is the platform shell, simulated browser entry point, API health check, and development architecture. Domain registration, page publishing, search, and authentication are not implemented yet.

## Planned stack

- Next.js, React, TypeScript, Tailwind CSS
- Fastify API
- PostgreSQL and Prisma
- Zod validation
- Vitest and Playwright
- pnpm workspaces

See `docs/` for the product overview, architecture, roadmap, technical decisions, and development status.
